# GitHub-guide – Vores Camping v24.1

1. Brug repositoryet `VoresCamping2`.
2. Pak `VoresCamping2-docs-v24.1.zip` ud på computeren.
3. Erstat repositoryets eksisterende `docs/`-mappe med den udpakkede `docs/`-mappe.
4. Kontrollér, at `docs/.nojekyll` er med. Filen er skjult på nogle systemer.
5. Commit ændringerne direkte til `main`.
6. Lad **Settings → Pages** stå på **Deploy from a branch**, `main` og `/docs`.
7. Vent på den nye grønne Pages-kørsel.
8. Test først `status.html` og derefter appens hovedside.

Openrouteservice API-nøglen indsættes under **Indstillinger → Ruteplanlægning**. Den må ikke lægges i GitHub-filerne.
